# Ошибка на карте — карта выпусков

Одна страница со всеми выпусками канала. Мир, точка на месте каждого события,
клик — карточка с крючком и ссылками на площадки.

**Один файл, работает офлайн, ничего не грузит со стороны.**

    index.html

Смысл: это единственный адрес канала, который не принадлежит площадке.
Дзен может понизить, VK может сломать плеер, RuTube может перестать
показывать — ссылка на карту продолжает работать и ведёт куда надо.

## Как добавить выпуск

Открыть `index.html` в блокноте, найти массив `EPISODES` и дописать объект:

```js
{
  id: 'kursk',                       // латиницей, попадёт в адрес: .../#kursk
  year: 2000, when: '12 августа 2000',
  title: 'Название выпуска',
  hook: 'Крючок — то, что стоит в заголовке ролика',
  text: 'Два-три предложения. Не пересказ, а причина посмотреть.',
  where: 'Баренцево море',
  lat: 69.62, lon: 37.57,            // координаты события
  links: { rutube: '', dzen: '', vk: '', youtube: '' }
}
```

**Точка встанет сама.** Она считается из `lat` и `lon`, руками ничего
двигать не надо. Порядок в массиве не важен — выпуски всё равно
сортируются по году.

Координаты проще всего взять на любой карте: широта первая,
северная и восточная — со знаком плюс, южная и западная — с минусом.

## Как вставить ссылки на ролики

В `links` каждого выпуска. Кнопки появляются только у заполненных:

```js
links: {
  rutube:  'https://rutube.ru/video/...',
  dzen:    'https://dzen.ru/video/watch/...',
  vk:      'https://vkvideo.ru/video...',
  youtube: ''
}
```

Пока все четыре пустые, в карточке стоит «Ссылка появится, когда выпуск выйдет».

Внизу файла есть `CHANNEL` — туда телеграм и Boosty, они попадут в подвал.

## Ссылка на конкретный выпуск

Адрес с решёткой открывает карту сразу на нужной точке:

    https://.../oshibka-na-karte/#halifax

Это то, что стоит класть в описание конкретного ролика: человек попадает
не на общую карту, а на свой выпуск — и видит рядом остальные пять.

## Что где

| Экран | Как ведёт себя карта |
|---|---|
| Компьютер | весь мир целиком, широкая полоса |
| Телефон | Атлантика с полюсами, вертикально — иначе мир превратился бы в полоску |
| Клик по точке | подлетает к месту, появляется кнопка «Вся карта» |

## Про географию

Карта схематичная: контуры материков нарисованы грубо и намеренно,
это фон для точек, а не атлас. **Точки при этом стоят по настоящим
координатам** — проекция равнопромежуточная, широта и долгота ложатся
линейно. У полюсов всё растянуто по горизонтали: это свойство проекции,
а не ошибка рисунка.

Если понадобится подробнее прорисовать какой-то участок — контуры лежат
в объекте `LAND` в градусах, в формате `долгота,широта` через пробел.
